# 슬라이더 가로 폭 축소 설계

## 목표

슬라이더의 양 끝 숫자와 설명 라벨이 화면 좌우 패딩에 가려지지 않도록 트랙과 모든 인덱스의 가로 폭을 함께 줄인다.

## 동작

- 슬라이더 제목은 기존 전체 폭을 유지한다.
- 트랙, range input, 숫자 인덱스, 설명 라벨 영역은 좌우로 각각 16px 축소한다.
- 1·3·5 숫자와 각 설명 라벨의 가운데 정렬을 유지한다.
- 취침 시간대의 두 줄 설명과 다른 슬라이더의 단일 줄 설명을 모두 같은 축소된 좌표계에 배치한다.

## 구현

`Slider`의 제목 아래에 있는 슬라이더 본문을 `px-4` 컨테이너로 감싼다. 현재 트랙과 눈금에 적용된 `inset-x-[10px]`, 숫자와 설명 라벨에 적용된 `mx-[10px]`는 제거한다.

range input, 트랙, 눈금, 숫자, 설명이 모두 동일한 내부 컨테이너의 전체 폭을 사용하므로 각 인덱스의 퍼센트 위치와 `-translate-x-1/2` 중심 정렬은 그대로 유지된다.

## 검증

- 슬라이더 본문에 공통 `px-4` 가로 여백이 적용됐는지 확인한다.
- 개별 요소의 기존 10px 가로 보정이 제거됐는지 확인한다.
- 인덱스의 퍼센트 위치 계산과 가운데 정렬 클래스가 유지되는지 확인한다.
- 전체 테스트, 변경 파일 lint, 프로덕션 빌드를 실행한다.
